# OpenSite Commerce：PR-01 数据库基础实施

这一步继续开发 V0.7 工程包，而不是重新设计架构。

目前已经完成以下代码增量：

1. **租户事务执行器**：统一事务生命周期，在业务查询前设置租户上下文，并处理失败回滚、取消和异常退出。
2. **PostgreSQL 迁移工具强化**：加入数据库级事务锁、SHA-256 校验、重复执行检查和迁移漂移检测。
3. **数据库权限分离**：增加认证查询与公开域名解析专用角色，避免全部业务共用一个数据库权限身份。
4. **数据访问准备**：增加企业、站点、商品 SKU 的 `sqlc` 查询定义和 `pgx` 适配代码。
5. **自动化验证**：增加跨租户、RLS、数据库角色权限检查，以及 PostgreSQL 18 的 CI 验证流程。
