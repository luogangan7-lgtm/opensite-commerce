# ADR-071 — Transactional migrator and three database trust zones

Status: Accepted as implementation **design**, pending PostgreSQL 18 integration.
Date: 2026-10-11.

## Decision

- Keep migrations **forward-only**. Previously shipped 001–008 migrations
  remain byte-identical; all new DDL enters migration 009+.
- Serialize every per-version application/checksum inspection under the same
  PostgreSQL `pg_advisory_xact_lock`. Commit the migration DDL and journal row
  atomically. A drifted applied migration causes an error, never silent reuse.
- Database roles have three separate NOLOGIN permission envelopes:
  `app_runtime` (tenant business data), `app_auth` (credential verification),
  `app_domain_resolver` (verified public domain lookup).
- The Go domain executor calls `set_config('app.tenant_id',$1,true)` inside the
  same transaction it gives to sqlc. The supplied tenant ID must already be
  authenticated and authorized; the GUC is not itself authentication.
- No automatic creation of a privileged production LOGIN role or storage of
  credentials in the repository. Login identities are provisioned separately.

## Why

Unprotected migration check-then-apply has a concurrency race. A single
runtime database identity containing both password hashes and storefront
read access enlarges the impact of a SQL vulnerability. Separate roles and
explicit transaction-local context make the intended trust boundaries testable.

## Tradeoffs

More connection pools may be required for authentication and domain resolution.
RLS cannot resist arbitrary SQL execution by a principal allowed to set the
same tenant GUC; application authentication and strict query surfaces remain
mandatory. Some original migration 008 grants are broad and should be narrowed
with another additive migration after live PostgreSQL verification.

## Evidence threshold

These designs are NOT proven until `./scripts/check_pg.sh` runs against an
actual PostgreSQL 18 server, and sqlc v1.31.1 + pgx v5.10.0 generated code
compiles with Go >=1.25. The present authoring environment lacks those tools.
